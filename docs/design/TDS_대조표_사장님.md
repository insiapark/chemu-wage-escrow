# 체무 사장님 앱 v8 TDS 대조표

사장님 앱 v8의 컴포넌트를 공개 디자인 기준에 하나씩 맞춘 표입니다. 출처 태그의 주소는 `디자인_근거.md`에 있습니다. 토스 TDS는 수치와 구조만 참고했고, UI Kit 파일, @toss 패키지, 토스 아이콘과 그래픽은 파일에 넣지 않았습니다(AIT-LIC). 화면 번호는 오른쪽 화면 목록의 순서이자 사장님 앱 v8?i=번호`의 번호입니다.

## 측정 결과

같은 도구(`scripts/design-audit/audit.mjs`, 47화면)로 v7과 v8을 쟀습니다.

| 판 | 요약 줄 |
|---|---|
| v7 (전) | screens 47 \| small text 512 \| low contrast 347 \| small targets 62 \| screens with >1 filled CTA 2 \| radius values 2px 11px 20px 999px 10px 14px 18px 9px 13px 22px 26px 30px 8px 12px 3px 6px |
| v8 (후) | screens 47 \| small text 496 \| low contrast 346 \| small targets 62 \| screens with >1 filled CTA 0 \| radius values 16px 9999px 8px 24px |

v8 목표 두 가지는 맞췄습니다. 채운 버튼이 둘 이상인 화면은 2개(19 보관함 채우기, 24 보관된 돈을 꺼내려 할 때)에서 0개가 됐고, 모서리 값은 16가지에서 8, 16, 24, 9999px 네 가지가 됐습니다(휴대폰 틀은 측정하지 않음). v9, v10에서 다룰 세 항목은 화면마다 v7보다 늘어난 곳이 없습니다. 작은 글자는 제목과 부제목을 TDS-Top 크기로 키우면서 16건 줄었고, 명암비 미달은 세그먼트 글자를 본문색으로 바꾸면서 1건 줄었고, 44px 미만 누르는 대상은 같습니다. 측정 도구는 휴대폰을 창 높이에 맞춰 약 0.88배로 줄여 재므로, 44px로 만든 아이콘 버튼도 39px로 잡혀 작은 대상에 남습니다.

채운 버튼 0개는 두 가지로 맞췄습니다. 보관함(17, 18)의 "보관함 채우기"를 채워 둔 돈 카드 안 옅은 버튼으로 옮겨, 채우기 시트(19)를 열면 시트의 "₩222,912 채우기" 하나만 채운 버튼입니다. 시트와 다이얼로그가 열리면 뒤 화면은 inert가 되고, 시트나 다이얼로그에 가려진 뒤 화면의 하단 CTA는 숨깁니다(24에서 다이얼로그 아래 "채워 둔 돈 꺼내기"). 가려진 자리라 화면 모습은 같고, 보조기기와 측정 도구에는 지금 누를 수 있는 채운 버튼 하나만 남습니다.

문구 린트(`textdump.mjs`, `lint.mjs owner`) 결과는 점검 기록에서 다시 돌릴 수 있습니다. 남은 지적은 21과 38의 "테스트넷 모의 원화 토큰(KRWt)" 안내 두 곳뿐입니다(예외로 둔 문장).
