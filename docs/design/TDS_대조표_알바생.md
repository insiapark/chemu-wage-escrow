# 체무 알바생 앱 v8 TDS 대조표

대상 파일은 알바생 앱 v8입니다. 화면 번호는 오른쪽 화면 목록의 `?i=N` 번호(0~79)이고 v7과 같습니다. 출처 태그의 주소와 확인 방법은 같은 폴더의 `디자인_근거.md`에 있습니다. 토스 TDS는 수치와 구조만 참고했고 UI Kit 파일, @toss 패키지, 토스 아이콘과 그래픽은 넣지 않았습니다(AIT-LIC). 값은 모두 체무 CSS에 직접 적었습니다.

## 측정

`scripts/design-audit/audit.mjs`로 80화면을 같은 조건(창 440x900, 화면 목록 번호마다 한 번)에서 쟀습니다.

v7 전 (`v7/알바생 앱 v7)

```
screens 80 | small text 996 | low contrast 981 | small targets 406 | screens with >1 filled CTA 10 | radius values 2px 8px 10px 12px 6px 4px 9px 13px 14px 3px 16px 999px
```

v8 후 (`v8/알바생 앱 v8)

```
screens 80 | small text 938 | low contrast 964 | small targets 400 | screens with >1 filled CTA 0 | radius values 16px 9999px 8px 24px
```

| 항목 | v7 | v8 | 목표 |
|---|---|---|---|
| 채운 버튼 2개 이상인 화면 | 10 | 0 | 0 |
| 모서리 값 종류 | 12가지(2, 3, 4, 6, 8, 9, 10, 12, 13, 14, 16, 999px) | 4가지(8, 16, 24, 9999px) | 8, 16, 24, 9999px 안 |
| 12.5px 이하 글자 | 996 | 938 | v9에서 0, 이번에는 늘지 않기 |
| 명암비 미달 | 981 | 964 | v9에서 0, 이번에는 늘지 않기 |
| 작은 터치 대상 | 406 | 400 | v10에서 0, 이번에는 늘지 않기 |

세 항목 모두 80화면 가운데 v7보다 늘어난 화면이 없습니다. 화면별 결과는 점검 기록, 점검 기록에 있습니다.

채운 버튼은 맨 위 화면, 열린 시트, 열린 다이얼로그, 탭바에서 화면 너비의 40% 이상이고 높이 40px 이상인 어두운 채운 버튼을 센 값입니다. v7에서 두 개로 잡힌 10화면(19, 46, 70, 71, 73~78)은 시트나 다이얼로그의 주 버튼과 그 아래 덮인 화면의 하단 CTA가 함께 잡힌 경우였습니다. v8은 시트나 다이얼로그가 열리면 덮인 하단 CTA를 가리고 아래 화면을 inert로 막습니다. 다이얼로그의 짧은 두 버튼은 같은 너비로 나란히 놓여 각각 화면 너비의 약 39%라 세지 않고, 버튼을 세로로 쌓은 74번은 "수정 요청하기" 하나로 잡힙니다. 70번은 출퇴근 화면의 큰 퇴근하기 버튼 하나로 잡힙니다.

측정 창 440x900에서는 폰 틀이 약 0.89배로 줄어 그려져 44px 대상이 39px로 잡힙니다. v10에서 작은 터치 대상을 0으로 만들 때 이 배율을 같이 봐야 합니다.

문구 린트(점검 기록)에 남은 것은 v7과 같은 10건입니다. 목록 칸처럼 생긴 버튼 8건(3번 받을 곳 선택 줄, 8번과 61번 일당 풀이 줄, 9번 달력 날짜 칸 5개)과 KRWt 안내 2건(51, 52번)이고, 새로 생긴 버튼 문구는 모두 통과했습니다.
