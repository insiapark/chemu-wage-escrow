# 체무 사장님 앱 v43 컴포넌트 목록

사장님 앱 `docs/chemu/v40/owner_v40.html`(69화면)에서 쓰는 부품 표이고, 레포 `docs/design/컴포넌트_사장님.md`(v15, 54화면)의 다음 판입니다. 쓰는 화면은 화면마다 머리 없는 크롬(창 480x1200, 휴대폰 화면 393x852, 글자 100%)으로 `owner_v40.html?i=번호`를 열어 맨 위 층(확인 창이 열려 있으면 확인 창, 시트면 시트, 전체 화면이면 전체 화면, 아니면 지금 화면과 탭바)에 보이는 것을 센 값입니다. 크기는 그때 잰 px이고, 글자 단계는 `--type-t1`~`--type-t7`(30, 26, 22, 20, 17, 15, 13px), 간격은 `--space-*` 토큰 이름입니다. 토큰 값은 레포 `docs/design/tokens.json`(v9, 68개)과 같고, 그 뒤에 더한 것은 움직임 토큰(`--motion-*`, v14)뿐입니다. 그림 규격은 `../../v42/그림_규격.md`, 화면 읽기 이름은 `../../v16/UX_WRITING_RULES.md` 8절, 에러 틀은 `../../v13/ERRORS_owner.md`를 따릅니다.

부품 이름 뒤 (새)는 v15 목록에 없던 부품입니다(16개: 표 15줄과 8절).

모든 부품에 공통인 것
- 누르는 대상은 44x44px 이상, 대상 사이는 8px 이상입니다.
- 키보드로 옮긴 포커스에만 2px 보라 테두리(`:focus-visible`, `--fg-brand`)를 보입니다.
- 상태는 색과 함께 글자나 아이콘 모양으로도 보입니다.
- 글자는 rem 단위라 글자 크기를 따라 커집니다. 130% 이상이면 나란한 버튼을 세로로 쌓고, 200%에서 화면 제목(`.lead-t`, `.state-t`, 결과 제목, 시트와 확인 창 제목)은 36px에서 멈춥니다.
- 모서리는 8, 16, 24, 9999px 네 가지(`--radius-s`, `--radius-m`, `--radius-l`, `--radius-full`)만 씁니다.
- 그림은 세 단계(히어로 208px, 작은 사물 96px, 행 아이콘 40px)뿐이고 모두 `alt=""`와 `aria-hidden="true"`입니다. 화면 높이 700px 이하(360x640)에서는 히어로 168px, 작은 사물 80px로 줄입니다.
- 움직임은 완료 순간에만 있고 움직임 줄이기에서는 모두 꺼집니다.

화면 번호는 PANEL 번호(`owner_v40.html?i=번호`, 00~68)입니다. v15와 어긋나는 곳: 50은 v15에서 확인 창(`dlg:fillFail`)이었고 v26부터 전체 화면 에러(`m:fillFail`)이며, 54~68은 v31~v37에 더한 화면이라 v15에 없습니다(00~49, 51~53은 v15와 같은 화면이고 29, 42는 목록 이름만 "입금이 안 됐을 때", "채울 날짜 알리기"로 바뀜).

## 8. 화면 읽기 전용 글 (새)

보이는 글에 기호나 시각이 있으면 보이는 쪽은 `aria-hidden="true"`로 두고, 화면 읽기가 읽을 말을 눈에 보이지 않는 글로 따로 둡니다(8절). 지금 두 앱의 클래스 이름이 다릅니다.

| 앱 | 지금 클래스 | 만드는 곳 | 같은 이름이 다른 뜻으로 쓰이는 곳 |
|---|---|---|---|
| 사장님 앱 | `.vh` (clip, clip-path, 1px, `opacity:0`, `pointer-events:none`) | `a11yPass()`가 기호 든 글과 `data-sr` 묶음에, `row()`가 누를 수 없는 행 이름에, `step()`이 단계 앞 상태 말에 붙임 | `.sec-h .sr`은 섹션 머리 오른쪽에 보이는 회색 글(07 "11월 21일 토요일", 24 "급여일에 알바생에게 나가요", 34 "11월 보관된 돈") |
| 알바생 앱 | `.sr`(읽는 말)과 `.say`(보이는 글, `aria-hidden`) | 화면 그리기 뒤 같은 방식으로 붙임 | 없음 |
| 기록 맞춰 보기 웹 | `.sr` | 페이지 글에 직접 | 없음 |

합치는 안: 이름을 `.sr` 하나로 둡니다.
1. 사장님 앱의 `.sec-h .sr`(보이는 회색 글)을 `.sec-h .sec-r`로 먼저 바꿉니다. 이름이 겹친 채로 `.vh`를 `.sr`로 바꾸면 섹션 머리 글이 사라집니다.
2. `.vh`를 `.sr`로 바꿉니다. 규칙은 사장님 앱 것을 씁니다: `position:absolute; width:1px; height:1px; margin:-1px; padding:0; overflow:hidden; clip:rect(0 0 0 0); clip-path:inset(50%); white-space:nowrap; border:0; opacity:0; pointer-events:none`. 알바생 앱의 `.screen span.sr`처럼 범위를 좁히지 않고 어디서나 같은 뜻으로 씁니다.
3. 보이는 쪽 클래스는 알바생 앱의 `.say`(둘레 글 모양을 그대로 물려받음)로 맞춥니다. 사장님 앱은 지금 보이는 쪽에 클래스 없이 `aria-hidden`만 붙이므로, `.say`를 더해도 모양은 바뀌지 않습니다.
4. 건너뛰기 목록(사장님 `SR_SKIP`, 알바생 같은 목록)의 `.vh`를 `.sr`로 바꾸고, 읽기 덤프로 기호 남은 줄 0(입력값 13 제외)을 다시 확인합니다.
