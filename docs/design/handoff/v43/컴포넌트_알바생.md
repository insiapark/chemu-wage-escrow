# 체무 알바생 앱 v43 컴포넌트 목록

알바생 앱 `docs/chemu/v40/worker_v40.html`(104화면, 11월 28일 오전 기준 가장 최근 알바생 앱 파일)에서 쓰는 부품 표이고, 레포 `docs/design/컴포넌트_알바생.md`(v15, 83화면)의 다음 판입니다. 쓰는 화면은 화면마다 머리 없는 크롬(창 480x1200, 휴대폰 화면 393x852, 글자 100%)으로 `worker_v40.html?i=번호`를 열어 맨 위 층(확인 창이 열려 있으면 확인 창, 시트면 시트, 전체 화면이면 전체 화면, 아니면 지금 화면과 탭바)에 보이는 것을 센 값입니다. 크기는 그때 잰 px이고, 글자 단계는 `--type-t1`~`--type-t7`(30, 26, 22, 20, 17, 15, 13px), 간격은 `--space-*` 토큰 이름입니다. 토큰 값은 레포 `docs/design/tokens.json`(v9, 68개)과 `디자인_토큰_알바생추가.md`(아래 여백 `--space-dock-bottom`, 빗금 `--bg-stripe-critical` 등)를 따릅니다. 사장님 앱과 같은 부품은 이름과 토큰이 같고(`컴포넌트_사장님.md`), 값이 다른 곳은 각 줄과 9절에 있습니다.

부품 이름 뒤 (새)는 v15 목록에 없던 부품입니다(10개: 표 9줄과 8절).

모든 부품에 공통인 것
- 누르는 대상은 44x44px 이상, 대상 사이는 8px 이상입니다.
- 키보드로 옮긴 포커스에만 2px 보라 테두리(`:focus-visible`, `--fg-brand`)를 보입니다.
- 상태는 색과 함께 글자나 아이콘 모양으로도 보입니다.
- 글자는 rem 단위라 글자 크기를 따라 커집니다. 130% 이상이면 나란한 버튼을 세로로 쌓고, 200%에서 제목은 36px에서 멈추고 본문은 끝까지 커집니다.
- 모서리는 8, 16, 24, 9999px 네 가지만 씁니다.
- 그림은 세 단계(히어로 200px, 작은 사물 96px, 행 아이콘 40px)뿐이고 모두 `alt=""`와 `aria-hidden="true"`입니다. 화면 높이 700px 이하(360x640)에서는 히어로 168px, 작은 사물 80px로 줄입니다. 시트나 확인 창이 뜨면 덮인 화면의 그림은 숨깁니다.
- 움직임은 완료 순간에만 있고 `--motion-*` 토큰을 씁니다. 움직임 줄이기에서는 모두 꺼집니다.

화면 번호는 PANEL 번호(`worker_v40.html?i=번호`, 00~103)입니다. v15와 어긋나는 곳: 00~82는 v15와 같은 화면이고(40, 71은 목록 이름만 "사장님에게 알리기 전 문자 보기", "87,720원으로 확정 확인 창"으로 바뀜), 83~103은 v31~v37에 더한 화면이라 v15에 없습니다.

## 8. 화면 읽기 전용 글 (새)

알바생 앱은 읽는 말을 `.sr`(눈에 안 보이는 글), 보이는 글을 `.say`(`aria-hidden`, 둘레 글 모양을 그대로 물려받음)로 나눕니다. 사장님 앱은 같은 일을 `.vh`로 하고, `.sr`은 섹션 머리 오른쪽의 보이는 회색 글에 씁니다. 두 앱과 기록 맞춰 보기 웹을 `.sr` 하나로 합치는 안은 `컴포넌트_사장님.md` 8절에 있습니다. 알바생 앱에서 바꿀 곳은 한 군데입니다: `.screen span.sr`로 좁혀 둔 규칙을 `.sr`로 넓히고 `clip:rect(0 0 0 0)`와 `pointer-events:none`을 더합니다(사장님 앱 `.vh`와 같은 규칙).
