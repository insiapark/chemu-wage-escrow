# 체무 사장님 앱 v75 컴포넌트 목록

사장님 앱 `../owner_v75.html`(83화면)에서 쓰는 부품 표이고, `../../v43/handoff/컴포넌트_사장님.md`(v40 파일, 69화면)의 다음 판입니다. 값의 근거는 두 앱 기준표 `../../v61/handoff/두앱_기준값.md`(74곳, 줄 간격 토큰, 배지 다섯 뜻, 6절 74곳 밖, 9절 입력 칸)이고, 크기와 쓰는 화면은 v75와 화면이 같은 v74 파일을 머리 없는 크롬(창 480x1200, 휴대폰 화면 393x852, 글자 100%)에서 `?i=번호`로 열어 맨 위 층(확인 창이 열려 있으면 확인 창, 시트면 시트, 전체 화면이면 전체 화면, 아니면 지금 화면과 탭바)에 보이는 부품을 잰 값입니다(`../../v51/_tools/quick/compscan.mjs`, 선택자 88개). 글자는 `크기/굵기/줄 높이`(px), 안 여백은 `위 오른쪽 아래 왼쪽`, 간격은 `--space-*` 토큰 이름입니다.

부품 이름 뒤 (새)는 v43 목록에 없던 부품이나 갈래입니다. 화면 번호는 PANEL 번호(`owner_v75.html?i=번호`, 00 ~ 82)이고 00 ~ 68은 v43과 같은 화면입니다. 69 ~ 82는 v63 ~ v74에 PANEL 끝에 더한 상태입니다(69 꺼내기, 70 일부만 먼저 채우기 확인 창, 71 내 기록 그대로 두기 시트, 72 ~ 76 입력 상태, 77, 78 길 잇기, 79 ~ 82 결정안과 맞춘 상태).

모든 부품에 공통인 것
- 누르는 대상은 44x44px 이상, 대상 사이는 8px 이상입니다. 달력 격자만 칸 사이 4(기준표 6절 예외, 사장님 앱에는 없음).
- 간격은 `:root`의 `--space-*`만 씁니다(4, 8, 12, 16, 24와 `--space-gutter` 24, `--space-component` 12, `--space-section` 24, `--space-screen-bottom` 56, `--space-safe-bottom` 34, `--space-dock-bottom`, `--space-tabbar-clear`). spaceaudit 0.
- 글자는 일곱 단계(t1 30/40, t2 26/35, t3 22/31, t4 20/29, t5 17/25.5, t6 15/22.5, t7 13/19.5)이고 크기를 정하는 규칙마다 같은 단계의 줄 간격 토큰(`--lh-t*`)을 함께 씁니다. `line-height: normal`은 없습니다. 따로 크게 보이는 금액과 시각은 고정폭 숫자(`tabular-nums`). typeaudit 0.
- 글자는 rem 단위라 글자 크기를 따라 커집니다. 130% 이상이면 나란한 버튼을 세로로 쌓고 배지는 줄을 바꿉니다. 200%에서 화면 제목은 36px에서 멈춥니다.
- 키보드로 옮긴 포커스에만 2px 보라 테두리(`:focus-visible`, `--fg-brand`)를 보입니다. 입력 칸은 칸 테두리가 2px 보라가 됩니다.
- 상태는 색과 함께 글자나 아이콘 모양으로도 보입니다(배지 다섯 뜻, 진행 단계 상태 말).
- 모서리는 8, 16, 24, 9999px 네 가지(`--radius-s`, `--radius-m`, `--radius-l`, `--radius-full`)만 씁니다.
- 그림은 세 단계(히어로 208px, 작은 사물 96px, 행 아이콘 40px)뿐이고 모두 `alt=""`와 `aria-hidden="true"`입니다. v58부터 2판 경로(`iso_v2_web`, `icon3d_v2_lg`, `icon3d_v2_web`)를 함께 씁니다.
- 움직임은 화면이 열릴 때 히어로 떠오름과 완료 순간의 작은 사물뿐이고 모두 320ms 이하 한 번, 움직임 줄이기에서는 모두 꺼집니다(v67).

## 8. 화면 읽기 전용 글

v63에서 `.vh`를 `.sr` 하나로 합쳤습니다(v43 8절의 안대로, 섹션 머리 오른쪽 회색 글은 먼저 `.sec-r`로). 세 화면(두 앱과 기록 맞춰 보기 웹)이 같은 규칙을 씁니다: `position:absolute; width:1px; height:1px; margin:-1px; padding:0; overflow:hidden; clip:rect(0 0 0 0); clip-path:inset(50%); white-space:nowrap; border:0; opacity:0; pointer-events:none`.

| 대상 | 보이는 쪽 | 읽는 쪽 |
|---|---|---|
| 기호 든 글(시각, 범위, 계좌, 기록 번호, 계산식) | `aria-hidden="true"` | `.sr`(규칙집 8절의 읽는 말) |
| 누를 수 없는 행 | 칸마다 `aria-hidden` | 쉼표로 이은 이름 하나 |
| 진행 단계 | 원 색과 아이콘 | 단계 앞 상태 말(끝남, 지금, 확인 필요, 문제 있음, 다음) |
| 글자 200%의 다른 가게 띠 | 아이콘과 "다른 가게" | 가게 이름 |

읽기 덤프에서 기호 남은 줄은 입력값 둘(13, 71 고치는 이유와 그대로 두는 이유)뿐입니다.
