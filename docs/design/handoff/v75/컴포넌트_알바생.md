# 체무 알바생 앱 v75 컴포넌트 목록

알바생 앱 `../worker_v75.html`(115화면)에서 쓰는 부품 표이고, `../../v43/handoff/컴포넌트_알바생.md`(v40, 104화면)의 다음 판입니다. 값은 두 앱 기준표 `../../v61/handoff/두앱_기준값.md`와 v75 화면을 기준으로 다시 잡았습니다.

- 쓰는 화면과 크기: 머리 없는 크롬(창 480x1200, 시안 틀 393x852, 글자 100%)으로 `worker_v75.html?i=번호`를 열어 맨 위 층(확인 창이 열려 있으면 확인 창, 시트면 시트, 전체 화면이면 전체 화면, 아니면 지금 화면과 탭바)에 보이는 부품을 센 값입니다. 도구는 `../../v51/_tools/quick/compscan.mjs`, 부품 선택자는 `../../v51/_tools/compsel_worker.json`, 표로 묶는 것은 `../../v51/_tools/compmap.mjs`입니다(README "compmap.mjs" 절). 115화면 측정 실패 0, 층은 지금 화면 73, 전체 화면 23, 시트 7, 확인 창 12입니다.
- 간격, 글자, 모서리: 앱 `:root` 토큰 이름입니다. 간격은 `--space-1` ~ `--space-6`(4, 8, 12, 16, 24)과 `--space-gutter` 24, `--space-component` 12, `--space-section` 24, `--space-dock-bottom`(max(34, 안전 영역, 20))만 씁니다(spaceaudit 0). 글자는 일곱 단계 `--type-t1` ~ `--type-t7`(30, 26, 22, 20, 17, 15, 13px)과 같은 단계의 줄 간격 `--lh-t1` ~ `--lh-t7`(40, 35, 31, 29, 25.5, 22.5, 19.5px)만 씁니다(typeaudit 0). 표의 `17/600/1.5`는 크기/굵기/줄 간격입니다.
- 값이 사장님 앱과 같은 부품은 이름과 토큰이 같습니다. 일부러 다른 값으로 둔 곳(앱 갈래)은 9절에 있습니다.

모든 부품에 공통인 것

- 누르는 대상은 44x44px 이상, 대상 사이는 8px 이상입니다. 예외는 근무 달력 칸 사이 4px 하나입니다(기준표 6절, 칸 44px을 지키려고).
- 키보드로 옮긴 포커스에만 2px 보라 테두리(`:focus-visible`, `--fg-brand`)를 보입니다. 입력 칸은 칸 테두리 하나가 보라 2px이 됩니다.
- 상태는 색과 함께 글자나 아이콘 모양으로도 보입니다(배지 다섯 뜻, 진행 단계 원 아이콘, 근무 칸의 체크와 점선).
- 글자는 rem 단위라 사용자 글자 크기를 따릅니다. 130% 이상이면 나란한 버튼을 세로로 쌓고 꾸밈 그림(히어로, 작은 사물)을 숨깁니다. 200%에서 제목과 큰 금액은 36px(1.125rem)에서 멈추고 본문은 끝까지 커집니다.
- 모서리는 8(`--radius-s`), 16(`--radius-m`), 24(`--radius-l`), 9999(`--radius-full`) 네 가지만 씁니다.
- 금액과 시각을 따로 보여 주는 칸(제목 금액, 카드 금액, 행 오른쪽 값, 행과 단계 보조 줄, 시각 칸, 버튼)은 `font-variant-numeric: tabular-nums`입니다. 문장 속 숫자는 그대로입니다.
- 그림은 세 단계(히어로 200px, 작은 사물 96px, 행 아이콘 40px)와 돈이 움직이는 길 네 칸뿐이고 모두 `width`, `height`, `alt=""`, `aria-hidden="true"`입니다. 화면 높이 700px 이하에서는 히어로 168px, 작은 사물 80px. 시트나 확인 창이 뜨면 덮인 화면의 그림을 숨깁니다. 2판 그림은 `../../assets/iso_v2_web/`(640px WebP), `icon3d_v2_lg/`(336px), `icon3d_v2_web/`(160px), 1판은 `iso_web/`, `icon3d_lg/`, `icon3d_web/`입니다.
- 움직임은 v67 규칙입니다. 화면을 여는 순간 히어로가 아래 8px에서 떠오름 320ms, 완료 순간(15, 33, 47, 85, 114)의 작은 사물은 0.92배에서 1배로 커지며 떠오름 320ms, 방금 끝난 단계의 체크 그리기 240ms(80ms 뒤). 가속도 곡선 `cubic-bezier(.2,.8,.2,1)` 하나, 무한 반복 없음, 움직임 줄이기면 모두 끄고 앱이 열려 있는 동안 바뀌어도 따릅니다. 금액 숫자는 세는 움직임이 없습니다.

화면 번호는 PANEL 번호(`worker_v75.html?i=번호`, 00 ~ 114)입니다. 00 ~ 103은 v43 목록과 같은 화면이고(이름은 v46, v58에서 시점을 붙이는 등 바뀐 것이 있음), 104(v65), 105 ~ 109(v66 입력 오류 상태), 110 ~ 112(v68 이어지는 화면), 113, 114(v74 사건 틀)가 더해졌습니다.
