# 체무 사장님 앱 v78 화면 표

사장님 앱 `docs/chemu/v78/owner_v78.html` 83화면(PANEL 번호 00 ~ 82, `owner_v78.html?i=번호`)의 표입니다. 캡처는 `../review/owner_cap_v78/번호.png`(창 480x1200, 2배, 파일 이름은 PANEL 번호 두 자리)입니다. v49 화면 표(`../../v49/handoff/화면표_사장님.md`, 69화면)의 다음 판입니다.

- 제목: 맨 위 층의 제목입니다. 확인 창이 열린 화면은 확인 창 제목, 시트가 열린 화면은 시트 제목, 그 밖은 본문 큰 제목입니다.
- 그림: 그 화면에 보이는 그림입니다(창 480x1200에서 잰 폭, isoaudit3). 히어로 208px, 작은 사물 96px, 행 아이콘 36px(40px 칸 안 그림)이고 21은 네 칸 장면입니다. 시트와 확인 창 화면은 아래 깔린 화면의 그림도 함께 셉니다. 모든 그림은 빈 alt와 aria-hidden입니다.
- 이어지는 알바생 화면: 화면 목록 패널의 "알바생 앱에서 이어지는 화면" 링크와 같고, 번호는 알바생 앱 `worker_v78.html?i=번호`의 PANEL 번호입니다.
- 시연 단계: 1분 시연 모드(`../../v78/demo_v78.html`) 12단계 가운데 이 화면이 사장님 앱 자리에 놓이는 단계입니다. (앞)은 그 단계에서 사장님 앱이 앞에 나오는 단계입니다.
