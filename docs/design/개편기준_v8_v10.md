# 체무 와이어프레임 v8 ~ v10 기준서: AI 티를 공개 기준으로 걷어 내기

근거 문서는 `디자인_근거.md`(같은 폴더)입니다. 규칙마다 출처 태그가 붙어 있습니다. 체무는 앱인토스 미니앱이 아니라서 토스 TDS는 수치와 구조만 참고하고, UI Kit 파일, @toss 패키지, 토스 아이콘과 그래픽은 넣지 않습니다(AIT-LIC).

측정 도구: `scripts/design-audit/audit.mjs` (사용법은 `scripts/design-audit/README.md`)
`node scripts/design-audit/audit.mjs <html 절대경로> <결과 json 절대경로> <화면 수>` 를 돌리면 화면마다 12.5px 이하 글자, 명암비 미달, 44px 미만 터치 대상, 채운 주 버튼 수, 모서리 값 종류를 셉니다. v5 알바생 앞 6화면만 재도 작은 글자 15, 명암비 미달 24, 작은 터치 대상 9건이 나왔습니다.

## v8: 토스 TDS 구조 대조 (화면의 뼈대)
1. 화면 좌우 여백 24px 하나. 표가 넓은 화면만 20px. [TDS-ListRow, SEED-Spacing]
2. 세로 간격은 8, 12, 16, 24px 네 단계. 리스트 행 상하 패딩 기본 12px, 행 왼쪽 아이콘은 40px 원 또는 24px 아이콘. [TDS-ListRow]
3. 모서리는 8(입력, 작은 칩), 16(카드, 버튼), 24(바텀시트 위쪽), full(배지, 알약 칩) 네 값만. [SEED-Radius, SEED-BottomSheet]
4. 채운 주 버튼은 한 화면에 하나. 나머지는 옅은(weak) 버튼이나 텍스트 버튼. 버튼 세 개 이상을 나란히 두지 않음. [TDS-Button, SEED-ActionButton]
5. 큰 제목 영역(Top)은 22px 또는 28px 굵게, 부제목 17px. 상단 바 높이 56px, 뒤로 가기는 이전 화면, 닫기(X)는 시트와 독립 흐름 끝. [TDS-Top, SEED-TopNav]
6. 바텀시트: 제목 필수, 최대 높이 화면의 90%, 위쪽 모서리 24px, 좌우 16px. 보관, 확정, 지급, 정산처럼 되돌리기 어려운 시트는 위쪽 닫기 버튼을 두고 손잡이를 뺌. 나머지 시트는 손잡이와 바깥 누르면 닫힘. [SEED-BottomSheet, TDS-BottomSheet]
7. 다이얼로그 왼쪽 버튼은 "닫기". 짧으면 가로, 길면 세로로 쌓음. [AIT-UX, TDS-Dialog]
8. 토스트는 하단 고정 CTA 위에, 3초(버튼이 있으면 5초). [TDS-Toast]
9. 하단 고정 CTA의 아래 여백은 max(env(safe-area-inset-bottom), 20px). [TDS-BottomCTA]
10. 장식 그라데이션, 글로우, 파티클을 뺌(사장님 앱 먹색 카드의 보라 글로우 포함). 그라데이션은 하단 CTA 페이드와 스켈레톤에만. [AIT-UX, SEED-Gradient]
11. 3D는 화면당 하나, 아이콘과 이모지는 24~40px로 한 번에 하나. [AIT-UX]
12. 버튼 문구는 누른 뒤 결과가 보이는 동사구, 마침표 없음. [AIT-UX, AIT-BLOG, SEED-Writing]
산출물: 알바생 앱 v8, 사장님 앱 v8, `TDS_대조표.md`(컴포넌트마다 출처, 체무 값, 바꾼 화면).

## v9: 오픈소스 디자인 시스템 기준 토큰과 명암비 (화면의 살)
1. CSS 변수를 역할 이름으로 다시 정의합니다. 속성 fg, bg, stroke × 역할 neutral, brand, positive, warning, critical, informative. 예: `--fg-neutral`, `--fg-neutral-muted`, `--bg-layer-default`, `--bg-layer-basement`(따뜻한 회색 바탕), `--bg-brand-solid`, `--fg-warning`, `--bg-warning-weak`, `--stroke-neutral-weak`. 기존 성재 님 값은 그대로 이 이름에 담습니다. [SEED-Color]
2. 간격 토큰 `--space-gutter: 24px`, `--space-component: 12px`, `--space-section: 24px`, `--space-screen-bottom: 56px`. 모서리 토큰 `--radius-s: 8px`, `--radius-m: 16px`, `--radius-l: 24px`, `--radius-full: 9999px`. [SEED-Spacing, SEED-Radius]
3. 글자 크기 단계 30, 26, 22, 20, 17, 15, 13px만 쓰고 12.5px 이하는 없앱니다. 크기는 rem으로 바꿔 사용자 글자 크기를 따르게 합니다. [TDS-Type, SEED-Type, HIG-A11y]
4. 명암비는 본문 4.5:1, 큰 글자와 UI 부품 3:1(WCAG 2.2). 계산해 둔 바꿀 값:
   | 지금 | 바탕 | 명암비 | 바꿀 값 | 명암비 |
   |---|---|---|---|---|
   | 보조 글자 #8a8792 | 흰색 | 3.52 | #6e6b76 | 5.21 |
   | 보조 글자 #8a8792 | #f4f3f0 | 3.17 | #66636e | 5.29 |
   | 주의 글자 #c27200 | #faefdc | 3.24 | #8f5200 | 5.47 |
   | 안내 글자 #0f8574 | #e1f2ef | 3.92 | #0a6658 | 5.94 |
   | 위험 글자 #d6383e | 흰색 | 4.67 | 그대로 | |
   | 위험 글자 | 옅은 빨강 바탕 | 미측정 | #c02a30 on #fdecec | 5.09 |
   주의색 #c27200, 안내색 #0f8574 자체는 아이콘과 점(3:1 기준)에는 그대로 쓰고, 글자에만 진한 값을 씁니다.
5. 상태는 색만으로 알리지 않습니다. 칩에는 글자가, 경고에는 아이콘과 글자가 같이 있습니다. [SEED-Inclusive, WCAG]
산출물: 알바생 앱 v9, 사장님 앱 v9, `디자인_토큰.md`와 `tokens.json`(이름, 값, 쓰임, 출처).

## v10: 접근성 마무리와 깃헙 푸시
1. 모든 탭 대상 44×44px 이상(보이는 아이콘이 24px이어도 누르는 영역은 44px), 대상 사이 8px 이상. [HIG-A11y, SEED-Inclusive, WCAG-2.5.5]
2. 아이콘만 있는 버튼에는 aria-label, 안의 svg에는 aria-hidden. 시트와 다이얼로그는 role="dialog", aria-modal="true", 보이는 제목을 aria-labelledby로. 닫으면 연 버튼으로 포커스 복귀. [FF-a11y, APG-Dialog]
3. 오른쪽 화면 목록 패널에 "글자 크기" 전환(100%, 130%, 200%)을 두고, 200%에서도 내용과 버튼이 사라지지 않게 고칩니다. [WCAG22 1.4.4, TDS-Type]
4. prefers-reduced-motion이면 화면 전환 움직임을 끕니다.
5. 점검 기준: audit 결과 작은 글자 0, 명암비 미달 0, 작은 터치 대상 0(시스템 상태 막대 제외), 채운 주 버튼 2개 이상인 화면 0, 모서리 값 {8, 16, 24, 9999}px 안.
6. 저장소 `docs/wireframe/`에 v10 두 파일, `docs/screens/`에 캡처, README와 화면기획서를 v10 기준으로 고쳐 `docs/readme-screen-plan` 브랜치로 푸시합니다(main 직접 푸시 금지).
