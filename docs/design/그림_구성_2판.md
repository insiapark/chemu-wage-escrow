# 체무 그림 장면 구성 규칙 2판 (v52)

`../v16/GRAPHIC_RULES.md`의 보충 절입니다. 화풍(30도 아이소메트릭, 무광 클레이, 팔레트, 바탕 #F4F3F0, 사람과 글자 없음)과 크기 3단계는 그대로이고, 한 장 안의 구성만 정합니다. v53부터 만드는 그림(`iso2_*`, `ic2_*`)은 모두 이 규칙을 따르고, 기존 44장은 아래 4절 표로 어긋난 곳을 적습니다. 규칙 번호는 C1~C9입니다.

## 1. 히어로 한 장의 구성

| 번호 | 규칙 | 기준 | 근거 |
|---|---|---|---|
| C1 | 주인공 사물 하나 | 화면 제목의 뜻을 진 사물 하나가 장면에서 가장 큽니다. 타일 윗면의 30~45%를 차지하고 타일 가운데나 왼쪽 앞에 섭니다. 크기가 비슷한 사물 둘이 나란히 서면 시선이 갈립니다 | R2, R12, R32 |

| C3 | 빛은 왼쪽 위 하나 | 사물의 윗면과 왼쪽 면이 가장 밝고 오른쪽 면이 어둡습니다. 발광(네온, 전등 빛, 밤 조명), 역광, 테두리 빛은 쓰지 않습니다 | R9, R30 |

| C7 | 떠 있는 장식 없음 | 공중에 뜬 색 조각, 소리 물결, 반짝이, 별, 쏟아지는 동전을 쓰지 않습니다. 움직임은 점선 길 하나까지만 씁니다 | R9, R28 |

## 2. 프롬프트 틀에 붙이는 구성 꼬리

`../v42/그림_규격.md` 4.1절 틀은 바꾸지 않고, `{장면}` 자리 끝에 아래 꼬리를 붙입니다. 참고 이미지로 기존 그림 두 장(히어로는 `iso_23_all_checked`, `iso_17_bell_on`, 아이콘은 `ic_safe`, `ic_clock`)을 넣습니다.

히어로 꼬리

```
{주인공} as the main object, with {받침 1~3개}, in the same matte clay style as the reference images, one soft key light from the upper left with soft shadows falling toward the lower right, nothing floating in the air, all grouped together with a wide empty margin
```

아이콘 꼬리

```
{사물}, in the same matte clay style as the reference images, bold simple shapes that stay readable at 40 pixels, one soft key light from the upper left with a soft shadow toward the lower right
```

모델이 묻지 않은 사물(동전, 리본 인장)을 더하는 일이 잦습니다. 뜻을 흐리면 `no coins, no seal and no ribbons`처럼 장면 자리 안에서 막습니다.

## 3. 만든 뒤 재는 법

| 항목 | 재는 법 | 기준 |
|---|---|---|
| 바탕 모서리 | 4.3절 명령(네 모서리 4x4 평균) | 채널마다 #F4F3F0과 7 이하 |
| 바탕 가장자리 | 그림을 256px로 줄여 바깥 4px 띠의 채널 차이 | 최대 7 이하 |
| 여백 | 바탕과 채널 차이 10 넘는 화소의 상자 | C6 |
| 그림자 쪽 | 채도 18 이하이고 바탕보다 5~45 어두운 화소의 무게중심을 사물 무게중심과 비교 | 좌우 치우침이 폭의 -8% 아래면 왼쪽 그림자로 보고 눈으로 다시 봄 |
| 줄여 보기 | 히어로 200px, 아이콘 96px과 40px로 나란히 | 윤곽, 주인공이 남는지 |

재는 스크립트는 작업 폴더 밖 스크래치 폴더의 `tools/imgstats.mjs`, `tools/border.mjs`입니다. 그림자 쪽은 타일 옆면의 회색이 섞여 오차가 있어 "추정"으로 적고, 왼쪽으로 나온 그림은 눈으로 다시 봅니다.
