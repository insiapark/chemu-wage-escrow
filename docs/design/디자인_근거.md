## 1. 토스 TDS Mobile (앱인토스 공개 문서)

### 1.1 문서 위치와 쓸 수 있는 범위

| 내용 | 확인 |
|---|---|
| 앱인토스 개발자 사이트의 TDS 소개 페이지는 핵심 컴포넌트 11개(Badge, Border, BottomCTA, Button, Asset, ListRow, ListHeader, Navigation, Paragraph, Tab, Top)를 소개하고, 각 상세 문서는 tossmini-docs.toss.im/tds-mobile/ 아래에 있습니다. Navigation 항목에는 링크가 없습니다. | [원문 확인] AIT-TDS |
| TDS Mobile 문서 목차에는 Foundation 2개(Colors, Typography)와 컴포넌트 약 50개(Agreement, Asset, BottomCTA, Chart, Dialog, Keypad, ListRow, TextField 묶음 포함)가 있습니다. | [원문 확인] https://tossmini-docs.toss.im/tds-mobile/ |
| 피그마 UI Kit 라이선스는 앱인토스 앱 개발, 앱인토스 앱 안의 디자인, 앱인토스 앱 프로토타입 제작만 허용합니다. 다른 프로젝트, 제품, 서비스에 키트 일부라도 쓰는 것, 복사, 수정, 재배포, 상업적 제공을 금지합니다. 위반하면 라이선스가 자동 종료되고 사본을 모두 지워야 합니다. 한국어본이 영어본보다 우선합니다. | [원문 확인] AIT-LIC |
| 코드 패키지(@toss/tds-mobile, @toss/tds-colors)의 이용 조건은 라이선스 페이지에 따로 적혀 있지 않습니다. npm 레지스트리에서 @toss/tds-mobile 최신판 2.5.1은 확인했지만 license 필드는 확인하지 못했습니다. | [원문 확인] https://registry.npmjs.org/@toss/tds-mobile/latest |
| 토스가 제공한 그래픽은 앱인토스 제휴 환경 안의 서비스 운영과 홍보 목적으로만 쓸 수 있습니다. | [원문 확인] AIT-UX |

체무는 앱인토스 미니앱이 아니므로 TDS는 수치 체계와 구조 원칙을 참고하는 데만 쓰고, UI Kit 파일, @toss 패키지, 토스 아이콘과 3D 그래픽은 화면에 넣지 않습니다. 값은 체무 자체 토큰 이름으로 다시 정의합니다.

### 3.2 SEED에서 가져올 규칙

1. 색은 원시값이 아니라 역할 이름으로 부릅니다. 체무 토큰도 fg, bg, stroke 속성과 brand, neutral, positive, warning, critical 역할을 조합해 짓습니다. [SEED-Color]
2. 화면 좌우 여백, 컴포넌트 사이 세로 간격, 제목 위 간격, 화면 아래 여백을 의미 간격 토큰으로 따로 정합니다. [SEED-Spacing]
3. 모서리 값은 토큰 목록 안에서만 고릅니다. [SEED-Radius]
4. 그라데이션은 스크롤 끝 페이드 마스크와 스켈레톤 반짝임에만 씁니다. [SEED-Gradient]
5. 채워진 강조 버튼은 한 화면에 하나, 버튼은 세 개 이상 나란히 두지 않습니다. [SEED-ActionButton]
6. 바텀시트는 제목 필수, 최대 높이 90%, 되돌릴 수 없는 작업에는 상단 닫기 버튼을 넣고 핸들을 뺍니다. [SEED-BottomSheet]
7. 글자 크기는 rem으로 써서 사용자 설정을 따르게 하고, 색만으로 상태를 알리지 않습니다. [SEED-Type, SEED-Inclusive]
8. 버튼과 제목에는 마침표를 찍지 않고, 완료 문구는 처리 상태가 아니라 사용자 행위로 씁니다. [SEED-Writing]

## 체무 v8~v9에 바로 쓸 규칙

1. TDS는 수치와 구조만 참고하고 토스 UI Kit, @toss 패키지, 토스 아이콘과 3D 그래픽은 체무 화면에 넣지 않습니다. [AIT-LIC, AIT-UX]
2. 화면 좌우 여백은 24px 하나로 통일하고 좁은 표 화면만 20px을 허용하며, 안전 영역이 있으면 그 경계부터 잽니다. [TDS-ListRow, SEED-Spacing]
