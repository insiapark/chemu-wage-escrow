# 체무 사장님 앱 v9 토큰

사장님 앱 v9의 `:root`에 있는 토큰 표입니다. 같은 내용을 `tokens.json`에 넣었습니다. 색 이름은 SEED Design처럼 속성(fg 글자와 아이콘, bg 바탕, stroke 선)과 역할(neutral, brand, positive, warning, critical, informative, layer)을 이어 지었고, 값은 성재 님 v3 값을 그대로 담되 명암비가 모자란 글자만 개편기준_v8_v10.md 표의 바꿀 값으로 바꿨습니다. 출처 태그의 주소는 `디자인_근거.md`에 있습니다. 명암비는 WCAG 2.x 상대 휘도 공식으로 직접 계산했고, 글자는 4.5:1, 큰 글자와 UI 부품은 3:1을 기준으로 봤습니다.

## 이름 짓는 법

| 부분 | 뜻 |
|---|---|
| fg | 글자와 아이콘 색 |
| bg | 화면, 카드, 버튼, 배지의 바탕 색 |
| stroke | 테두리와 구분선 |
| neutral | 일반 내용(먹색, 회색) |
| brand | 체무 보라, 강조할 것 |
| positive | 보관됨, 확정 같은 완료. 체무는 초록 계열이 하나라 informative와 같은 값 |
| warning | 주의(아직 보관 못 한 돈, 고친 기록, 수정 요청) |
| critical | 위험(알림 개수) |
| informative | 안내(보관됨 배지, 안내 상자) |
| layer | 깊이: basement(화면 바탕), default(카드), floating(다이얼로그) |
| solid, weak | 채운 바탕과 옅은 바탕 |
| muted, subtle, strong | 같은 역할 안에서 더 옅거나 진한 단계 |

보조 글자 `--fg-neutral-muted`는 놓인 바탕에 따라 값이 바뀝니다. 화면 바탕과 옅은 색 상자 위에서는 `#66636e`, 흰 카드와 목록, 다이얼로그 안에서는 `#6e6b76`입니다. 흰 카드 계열 선택자에서 변수를 다시 정의해 씁니다.
