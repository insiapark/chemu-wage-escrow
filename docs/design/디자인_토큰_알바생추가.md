# 체무 알바생 앱 v9 토큰

알바생 앱 v9은 사장님 앱 v9와 같은 토큰 이름과 값을 씁니다. 이름 짓는 법, 공통 토큰 전체 표, 명암비 계산은 같은 폴더의 `디자인_토큰.md`와 `tokens.json`에 있습니다. 이 문서에는 알바생 앱에만 있는 토큰, 공통 토큰을 알바생 앱에서 다르게 쓰는 자리, 바꾼 글자 크기와 색, 측정 결과만 적었습니다. 출처 태그의 주소는 `디자인_근거.md`에 있습니다.

v8까지 겹쳐 쌓인 v2~v8 스타일 층(`--c-ink`, `--c-mute` 같은 원시 이름)은 지우고, 화면 안 스타일을 토큰 한 층으로 다시 썼습니다. 휴대폰 틀과 오른쪽 화면 목록 패널은 측정 대상이 아니라 px 그대로 두었습니다.

## 알바생 앱에만 있는 토큰

| 이름 | 값 | 쓰임 | 출처 태그 | v8에서 |
|---|---|---|---|---|
| `--space-safe-bottom` | `34px` | 시안 폰 틀(iPhone)의 아래 안전 영역. 브라우저에서는 env 값이 0이라 틀 안에서 같은 여백을 보이려고 둠 | TDS-BottomCTA | `--safe-bottom` |
| `--space-dock-bottom` | `max(var(--space-safe-bottom), env(safe-area-inset-bottom, 0px), 20px)` | 하단 고정 CTA, 가입 하단 버튼, 시트 아래 버튼, 다이얼로그 아래 여백 | TDS-BottomCTA | 같은 식을 네 군데에 따로 씀 |
| `--bg-stripe-critical` | `repeating-linear-gradient(45deg, var(--fg-critical) 0 2px, var(--bg-layer-default) 2px 5px)` | 안 들어온 날 근무 칸과 범례의 빗금. 빨강만으로 알리지 않으려는 무늬 | SEED-Inclusive | 같은 값을 두 군데에 씀 |

v8의 `--weak`, `--weak-press`는 공통 토큰 `--bg-neutral-weak-alpha`, `--bg-neutral-weak-alpha-pressed`로 옮겼습니다.

## 공통 토큰을 알바생 앱에서 쓰는 자리

| 이름 | 사장님 앱 | 알바생 앱 |
|---|---|---|
| `--stroke-neutral-solid` | 금액, 날짜 입력칸 테두리 | 근무 중 카드, 고른 받을 곳 줄, 고른 비교 칸, 오늘 근무 칸 테두리 |
| `--bg-neutral-strong` | 꺼진 스위치, 근무표의 다른 알바생 칸 | 홈 카드의 확정 대기 칸(흰 시계 표시와 함께, 흰 카드 위 3.52:1) |
| `--stroke-neutral-strong` | 입력칸, 체크 상자, 세그먼트, 요일 칸 | 입력칸, 메모 칸, 체크 상자, 칩, 남은 근무 칸 점선, 시트 손잡이, 가입 진행 점 |
| `--fg-neutral-ui` | 목록 화살표, 연필 | 목록 화살표, 돈이 움직이는 길 화살표, 고를 수 없는 줄 아이콘 |
| `--bg-neutral-solid` | 먹색 카드, 채운 버튼 | 채운 버튼, 보관된 날 칸, 출퇴근 큰 버튼(출근과 퇴근 모두. v3의 퇴근 #444는 토큰에 없어 먹색으로 맞춤) |
| `--fg-neutral-muted` | 흰 카드 안에서 #6e6b76 | 같은 규칙. 흰 카드, 목록, 홈 카드, 종이, 단계, 달력, 문자 미리보기, 입력칸, 선택 줄, 다이얼로그, 탭바 안에서 #6e6b76, 그 밖은 #66636e |

## 글자 크기 (v8 px에서 v9 단계로)

모든 화면 안 글자는 `--type-t1`~`--type-t7`(30, 26, 22, 20, 17, 15, 13px, rem)만 씁니다. 13px보다 작은 글자는 없습니다. [TDS-Type, SEED-Type, HIG-A11y]

| v9 | v8에서 | 자리 |
|---|---|---|
| t1 30 | 30, 34, 40, 46px | 홈 카드 보관된 돈, 급여일 월급 금액, 근무 중 타이머(46에서) |
| t2 26 | 24, 28px | 탭 첫 화면 제목, 금액 머리, 결과 제목, 가입 제목, 출퇴근 제목, 출퇴근 큰 버튼. TDS-Top의 28(st2)은 일곱 단계에 없어 사장님 앱처럼 26으로 |
| t3 22 | 22px | 문장 제목, 상태 제목, 합계, 가운데 제목, 급여일 문장 제목 |
| t4 20 | 19, 20px | 시트와 다이얼로그 제목, 비교 칸 값, 인증번호 칸 |
| t5 17 | 16, 17, 18px | 버튼, 부제목과 설명, 상단 바 제목, 카드 제목, 입력값 |
| t6 15 | 13.5~15.5px | 목록 제목, 금액, 보조 설명, 작은 버튼, 토스트, 출퇴근 버튼, 날짜 칸 숫자 |
| t7 13 | 9~13px | 목록 보조 글, 배지, 탭바, 맺음 글, 달력 칸 상태 글자(9px에서, 두 줄까지), 범례, 알림 개수 |

## 상태를 색만으로 알리지 않음 [SEED-Inclusive, WCAG22]

| 자리 | 색 말고 함께 주는 단서 |
|---|---|
| 상태 배지(보관됨, 확정 대기, 고친 기록, 안 들어옴, 이의 제기 중) | 배지 글자 |
| 홈 카드 근무 칸 | 보관됨은 체크, 확정 대기는 시계(v9에서 더함), 안 들어옴은 빗금, 남은 근무는 점선, 오늘은 굵은 테두리. 아래 범례 글자 |
| 근무 달력 날짜 칸 | 칸마다 상태 글자(13px, 두 줄까지). 확정 대기와 남은 근무는 점선 테두리 |
| 단계 목록 | 단계마다 다른 아이콘(체크, 시계, 느낌표, 자물쇠)과 단계 글자 |
| 안내 상자(주의, 안내, 위험) | 24px 아이콘과 굵은 제목 글자 |
| 안 들어온 금액(빨강) | 옆의 "안 들어옴" 배지나 제목 "안 들어왔어요" |
| 근무 중 카드 | "근무 중" 배지와 머리 버튼 글자 "퇴근하기" |
| 고른 칩 | 먹색 바탕에 굵은 글자, aria-pressed |
| 고른 받을 곳 줄 | 2px 테두리와 체크 상자 체크 |
| 읽지 않은 알림 점 | 점이 있고 없음, 보조기기 이름 "읽지 않음" |
| 가입 진행 점 | 지금 단계 점이 두 배 길이 |
| 알림 설정 줄 | "켜짐", "꺼짐" 글자 |
| 고를 수 없는 받을 곳 줄 | "법이 정비되면 열려요 · 지금은 시연용" 글자와 aria-disabled |

## 측정 결과

`scripts/design-audit/audit.mjs`를 창 480x1200(폰 배율 1, 393px 화면 그대로)으로 80화면 모두 쟀습니다.

v8 (전)

```
screens 80 | small text 938 | low contrast 964 | small targets 70 | screens with >1 filled CTA 0 | radius values 16px 9999px 8px 24px
```

v9 (후)

```
screens 80 | small text 0 | low contrast 0 | small targets 68 | screens with >1 filled CTA 0 | radius values 16px 9999px 8px 24px
```

| 항목 | v8 | v9 | 목표 |
|---|---|---|---|
| 13px 미만 글자 | 938 | 0 | 0 |
| 명암비 미달 | 964 | 0 | 0 |
| 44px 미만 누르는 대상 | 70 | 68 | v10에서 0 |
| 채운 버튼 2개 이상인 화면 | 0 | 0 | 0 |
| 모서리 값 | 8, 16, 24, 9999px | 8, 16, 24, 9999px | 네 값 안 |

화면마다 비교해도 v8보다 늘어난 항목은 없습니다. 화면별 결과는 점검 기록, 점검 기록에 있습니다.

v8 대조표의 숫자(작은 터치 대상 406, 400)는 창 440x900에서 폰이 약 0.89배로 줄어 잰 값이라 위 표와 다릅니다. 이번에는 배율 1에서 쟀습니다.
