# 체무 사장님 앱 v14 움직임

사장님 앱 v14은 v13 화면, 숫자, 문구를 그대로 두고 움직임만 정리한 판입니다. 기준은 개편 기준 v11~v15의 v14 절입니다. 완료 순간에만 짧게 움직이고, 400ms 안에 끝나며, 반복하지 않고, 움직임 줄이기에서는 모두 꺼집니다.

## 움직임 표

모든 값은 `:root`의 토큰(`--motion-*`, `--ease-out`)으로 씁니다. 가속도 곡선은 v3부터 화면 전환에 쓰던 `cubic-bezier(.2,.8,.2,1)`(빠르게 시작해 부드럽게 멈춤) 하나입니다.

| 이름 | 무엇이 | 시간 | 가속도 곡선 | 쓰는 화면 |
|---|---|---|---|---|
| 떠오름 (rise) | 3D 그림이나 결과 표시 원이 아래 8px에서 제자리로, 투명에서 보이게 | 320ms | cubic-bezier(.2,.8,.2,1) | 10 확정 완료(3D), 15 이의 정리: A님 기록으로(결과 원), 28 자동 입금 완료(3D), 44 일부만 채운 뒤(결과 원), 45 아직 보관 못 한 돈 보관 완료(결과 원) |
| 체크 그리기 (draw) | 체크 표시 선이 처음부터 끝까지 그려짐 | 240ms, 80ms 뒤 시작(320ms에 끝) | cubic-bezier(.2,.8,.2,1) | 15 결과 원 안 체크, 10 첫 단계 "근무 확정", 45 마지막 단계 "B님 앱에 '보관됨'으로 바뀌었어요", 28 방금 끝난 입금 단계(단계마다 한 번) |
| 토스트 | 하단 버튼이나 탭바 바로 위에서 8px 아래부터 올라오며 나타남 | 200ms | cubic-bezier(.2,.8,.2,1) | 토스트가 뜨는 모든 화면(02, 03, 05, 11, 13, 17, 19, 22, 23, 24, 30, 32, 35, 36, 38, 39, 42, 48, 50, 51) |
| 바텀시트 | 아래에서 올라옴 | 240ms (v13 280ms) | cubic-bezier(.2,.8,.2,1) | 19 보관함 채우기, 14에서 여는 "내 기록을 유지할까요?" |
| 화면 전환 | 옆으로 밀림 | 300ms (v3 값 유지) | cubic-bezier(.2,.8,.2,1) | 쌓이는 모든 화면 |
| 전체 화면 열기 | 아래에서 올라옴 | 320ms (v3 값 유지) | cubic-bezier(.2,.8,.2,1) | 온보딩, 결과, 실패 화면 |

움직이지 않는 것: 금액 숫자(세는 움직임 없음), 실패와 에러 화면(29, 47~51), 빈 상태(52, 53), 이의 정리: 내 기록 유지(16, 받아들여지지 않은 결과), 목록과 카드, 3D 그림이 있는 안내 화면(00~02, 13, 14, 22, 32, 39). 정산 완료는 사장님 앱에 따로 완료 화면이 없어 해당 없음입니다(그만둔 알바 정산 46은 안내 화면).

## 지키는 규칙과 구현

| 규칙 | 구현 |
|---|---|
| 완료 순간만 | 전체 화면을 열 때 완료 화면(확정 완료, 보관 완료, 일부 보관 완료, 급여일 입금, 이의 받아들여짐)에만 `.moment`를 붙이고 450ms 뒤 뗍니다. 급여일 화면은 0.9초마다 다시 그려지지만 `.moment`가 이미 떼어져 3D가 되풀이되지 않고, 방금 끝난 단계(`.just`)만 체크를 한 번 그립니다 |
| 400ms 안 | 가장 긴 움직임이 320ms(떠오름, 그리고 80ms 뒤 시작하는 240ms 체크 그리기) |
| 무한 반복과 꾸밈 움직임 없음 | `infinite`가 파일에 없습니다. v3의 결과 원 "pop"(0.6배에서 커지기 350ms)을 떠오름으로 바꿨습니다 |
| 금액 숫자는 그대로 | 금액에는 움직임을 붙이지 않습니다 |
| 움직임 줄이기 | `prefers-reduced-motion: reduce`이면 CSS에서 모든 transition과 animation을 끄고, 스크립트도 `.moment`를 붙이지 않으며 화면 전환 대기 시간을 0으로 둡니다 |
| 캡처는 끝난 모습 | 캡처 주소(`?i=N`)에서는 `.cap`이 모든 움직임을 끄므로 기본 모습이 곧 끝난 모습입니다. 체크 선의 기본값은 다 그려진 상태(dashoffset 0)이고 떠오름의 기본값은 제자리입니다. 움직임은 열고 0.32초 안에 끝납니다 |
| 체크 그리기 선 두께 | 체크 경로에 `pathLength="1"`을 주고 그리는 동안만 `vector-effect`를 끄므로, 크기별로 선 두께를 1.9px로 맞춰 둡니다(결과 원 32px, 단계 16px, 체크 상자 14px) |

## 확인한 것

`motion_test.mjs`(임시 점검 스크립트)로 머리 없는 크롬(480x1200)에서 확인했습니다.

| 점검 | 보통 | 움직임 줄이기(--force-prefers-reduced-motion) |
|---|---|---|
| 10 확정 완료 | rise 320ms(3D), draw 240ms+80ms, 끝 320ms, 반복 1번 | 움직임 0개 |
| 15 이의 정리: A님 기록으로 | rise 320ms(결과 원), draw 240ms+80ms | 0개 |
| 45 보관 완료 | rise 320ms, draw 240ms+80ms | 0개 |
| 44 일부만 채운 뒤 | rise 320ms | 0개 |
| 29 입금 실패, 16 내 기록 유지 | 움직임 없음 | 0개 |
| 28 급여일 입금 | 열 때 rise 320ms, 0.9초 뒤 그 단계 draw 240ms만 | 0개 |
| 450ms 뒤 `.moment` | 떼어짐 | 붙지 않음 |
| 토스트, 시트, 화면 전환 | 0.2s, 0.24s, 0.3s | 0s |
| 반복(iterations Infinity) | 0개 | 0개 |

움직임만 바꿨으므로 다섯 목표가 그대로입니다. 캡처(`cap_owner/`, `_all.jpg`)는 모두 끝난 모습입니다.

## 문구 린트

`lint.mjs owner` 결과는 v13과 같습니다. 금지어는 21, 38의 "테스트넷 모의 원화 토큰(KRWt)" 안내 두 곳이고, 버튼 문법 9건은 시트나 확인 창을 여는 목록 행(role="button")의 행 전체 글자를 버튼 이름으로 읽은 것입니다(`접근성_점검_사장님.md` 참고). 문구는 바꾸지 않았습니다.
