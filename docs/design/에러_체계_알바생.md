# 체무 알바생 앱 v13 에러와 빈 상태

알바생 앱 v13은 v10 화면을 그대로 두고, 에러, 실패, 빈 상태를 한 틀로 맞춘 판입니다. 기준은 개편 기준 v11~v15의 v13 절, 토스 좋은 에러 메시지 6원칙(관련 문서 1부 2절), 에러 점검 메모의 알바생 줄입니다. 틀과 코드는 사장님 앱(`에러_체계_사장님.md`)과 같습니다. 점검 메모대로 긍정형 제목("가게 30m 안에서 출근할 수 있어요", "위치를 켜면 출근할 수 있어요")은 그대로 둡니다.

## 틀

| 순서 | 들어갈 것 | 지키는 원칙 |
|---|---|---|
| 1 | 제목: 무슨 일이 있었는지 사람 말로 한 줄. 시스템 말, 코드 번호 없음 | 사용자 입장에서 이해할 수 있는 언어 |
| 2 | 돈이 걸린 일이면 둘째 줄은 돈이 어디 있는지 | 부정적인 감정 최소화 |
| 3 | 이유와 할 수 있는 일 한두 줄 | 스스로 해결할 수 있는 방법 알려주기 |
| 4 | 주 버튼은 그 문제를 바로 푸는 동작, 물러나는 버튼은 "닫기" | 쉽게 해결할 수 있게 도와주기 |
| 5 | 색: 돈이 안 들어온 일만 위험(빨강), 기다림과 확인은 주의(주황), 안내와 빈 상태는 안내(초록). 색과 함께 아이콘과 글자 | 적절한 컴포넌트 쓰기 |
| 6 | 막을 수 있는 일은 누르기 전에 막기. 빈 상태는 왜 비어 있는지 한 줄과 다음 할 일 하나, 한 메시지 화면이면 3D 하나 | 최고의 에러는 발생하지 않는 것 |

화면에서는 `stateBlock()` 하나로 그립니다. 40px 원 아이콘(또는 3D 하나), 제목 22px(`.state-t`, h2), 돈 위치 17px 굵게(`.state-money`), 설명 15px(`.state-s`), 버튼 줄 순서입니다. 에러와 실패는 role="alert"로 바로 읽히고, 빈 상태와 기다림은 읽기를 끊지 않습니다. 오늘 화면과 하루 상세처럼 다른 내용 사이에 들어가는 알림은 안내 상자(`.callout`) 안에서 같은 순서(제목, 둘째 줄 `.c-money` 돈 위치, 설명)를 따릅니다. 출퇴근 전체 화면은 큰 버튼이 화면의 일이라 같은 순서를 출퇴근 머리(`.clock`)에서 지키고, 막혀 있으면 큰 버튼을 끄고 바로 푸는 동작을 채운 버튼으로 둡니다.

## 측정

같은 도구(`scripts/design-audit/audit.mjs`, 창 480x1200)로 v10 80화면과 v13 83화면을 쟀습니다.

| 판 | 요약 줄 |
|---|---|
| v10 (전) | screens 80 \| small text 0 \| low contrast 0 \| small targets 0 \| screens with >1 filled CTA 0 \| radius values 16px 9999px 8px 24px |
| v13 (후) | screens 83 | small text 0 | low contrast 0 | small targets 0 | screens with >1 filled CTA 0 | radius values 16px 9999px 8px 24px |
