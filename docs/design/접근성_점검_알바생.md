# 체무 알바생 앱 v10 접근성 정리

알바생 앱 v10은 v9 화면, 숫자, 문구를 그대로 두고 접근성만 마무리한 판입니다. 기준은 `개편기준_v8_v10.md`의 v10 절이고, 출처 태그의 주소는 `디자인_근거.md`에 있습니다. 방법과 코드 모양은 사장님 앱 v10(`접근성_점검_사장님.md`)과 같습니다.

## 측정 결과

같은 도구(`scripts/design-audit/audit.mjs`, 80화면)를 창 크기 480x1200으로 돌렸습니다. 이 크기에서 휴대폰 맞춤 배율 `fit()`이 1이라(창 안쪽 504x1104, 화면 폭 393px 그대로) 누르는 대상을 CSS 값 그대로 잽니다. v8 대조표의 400건은 440x900에서 약 0.89배로 줄여 잰 값이라 여기서는 v9를 다시 잰 값과 비교합니다.

v10 목표 다섯 가지(13px 미만 글자 0, 명암비 미달 0, 44px 미만 누르는 대상 0, 채운 버튼이 둘 이상인 화면 0, 모서리 값 8, 16, 24, 9999px)를 모두 맞췄습니다. 측정 도구는 상태 막대를 재지 않습니다. 화면별 결과는 점검 기록, 점검 기록에 있습니다.

## 바꾼 것

| 항목 | 출처 태그 | 체무 v10 |
|---|---|---|
| 누르는 대상 44x44px | HIG-A11y, SEED-Inclusive, WCAG-2.5.5 | 위 표의 대상을 모두 44px 이상으로 키웠습니다. 보이는 아이콘은 24px 그대로이고 단추 상자를 44px(상단 바 아이콘), 52px(시트 닫기)로 둡니다. 버튼, 배지, 칩, 위치 표시, 출퇴근 큰 버튼은 고정 높이 대신 최소 높이를 써서 글자가 커지면 같이 커집니다. 홈 카드의 "급여일까지 사장님도 꺼낼 수 없어요" 줄도 높이 44인 링크입니다 |
| 대상 사이 8px | Google-Touch, HIG-A11y | 탭바 네 칸 사이 8px, 칩 사이 8px, 하단 버튼 사이 8px, 다이얼로그 버튼 사이 8px, 상단 바 출퇴근과 알림 사이 8px입니다. 근무 달력은 일곱 칸이 44px 이상, 칸 사이 8px로 들어가게 좌우 20인 표 화면으로 두고 달력 상자를 양쪽 6px씩 넓혔습니다. 목록 행은 TDS ListRow처럼 서로 붙어 있지만 행마다 높이가 56px 이상이라 누르는 영역이 겹치지 않습니다 |
| 아이콘만 있는 단추 이름 | FF-a11y, TDS-Button | 뒤로 가기, 닫기, 시트 닫기, 알림에 aria-label이 있고, 알림은 "알림, 읽지 않은 알림 1개"처럼 개수를 함께 읽습니다. 모든 아이콘 svg에 aria-hidden="true"를 붙였고(휴대폰 화면 안 이름 없는 단추 0개, 가리지 않은 svg 0개), 상태 막대와 홈 표시줄 같은 휴대폰 틀도 aria-hidden입니다. 메모 칸 두 곳에 보이는 질문과 같은 이름을 붙였습니다 |
| 누르는 행을 키보드로 | FF-a11y | 누르는 목록 행, 안내 상자, 오늘 근무 카드, 휴게 확인 줄, 홈 카드 문장 줄에 tabindex="0"을 붙였습니다. 다른 화면으로 가는 것과 알림 줄은 role="link"(Enter), 시트나 확인 창을 여는 행은 role="button"(Enter, Space)입니다. 고르는 줄(받을 곳, 이의 제기의 다른 점, 가입의 받을 곳)은 role="radio"와 aria-checked, 기록 내보내기의 넣을 내용은 role="checkbox"입니다. 탭바의 지금 탭에는 aria-current="page", 고른 칩에는 aria-pressed를 둡니다 |
| 시트, 다이얼로그, 전체 화면 | APG-Dialog, Radix-Dialog, TDS-BottomSheet | 셋 다 role="dialog", aria-modal="true", 보이는 제목에 aria-labelledby로 잇습니다(시트 제목, 다이얼로그 제목, 전체 화면 상단 바 제목이나 가입 제목). 열려 있지 않은 층은 inert라서 Tab이 가려진 곳으로 가지 않고, 전체 화면은 닫혀 있으면 aria-hidden입니다 |
| 포커스 가둠과 돌려주기 | APG-Dialog, Radix-Dialog | 단추를 눌러 열면 포커스가 층 안 첫 요소로 들어가고(시트는 위쪽 닫기, 다이얼로그는 가장 안전한 "닫기"), Tab과 Shift+Tab은 층 안에서만 돌고, Esc나 닫기로 닫으면 연 단추로 돌아갑니다. 연 단추가 다시 그려져 사라졌으면 지금 화면의 첫 요소로 갑니다. 가입 흐름은 닫기 단추가 없는 독립 흐름이라 Esc로 닫지 않습니다. 화면 목록에서 바로 연 상태는 연 단추가 없어 포커스를 옮기지 않고, Tab을 누르면 층의 첫 요소로 들어갑니다. 화면이 다시 그려져도(칩 고르기, 받을 곳 고르기) 포커스는 같은 단추에 남습니다 |
| 74번 보호 창의 첫 포커스 | APG-Dialog | "수정 요청하기"와 "그래도 동의하기"가 모두 행동이라, 처음 포커스는 버튼이 아니라 제목에 둡니다. Enter를 잘못 눌러 주휴수당 없이 동의하는 일이 없습니다. 바깥 누르기와 Esc는 아무 동작 없이 닫습니다 |
| 쌓인 다이얼로그 버튼 순서 | APG-Dialog, WCAG22 | 버튼을 세로로 쌓을 때(글자가 길거나 글자 크기 130% 이상)는 확인 버튼을 위에 그리고 DOM 순서도 같게 해, 보이는 순서와 Tab 순서가 같습니다 |
| 글자 크기 전환 | WCAG22 1.4.4, TDS-Type | 오른쪽 화면 목록 패널 위에 "글자 크기 100%, 130%, 200%" 단추를 두었습니다. 휴대폰 안 글자는 v9에서 rem으로 바꿨으므로 뿌리 글자 크기만 바꿉니다. 주소 끝에 `&fs=200`(또는 `?fs=200`)을 붙여도 열립니다 |
| 200%에서 사라지거나 겹치지 않게 | WCAG22 1.4.4, 1.4.10 | 130% 이상에서 하단 버튼과 버튼 줄을 세로로 쌓고, 다이얼로그 버튼도 쌓습니다. 상단 바와 전체 화면 머리는 높이를 고정하지 않아 제목이 줄을 바꾸고, 목록 행은 금액이 다음 줄로 내려가며, 홈 카드는 D-19를 금액 아래로 내립니다. 기록 화면은 칩 줄과 "달력 보기"를 두 줄로 나누고, 입력칸 안 배지와 남은 시간은 라벨 아래로 내립니다. 비교 칸은 200%에서 한 줄에 하나, 근무 달력과 기록 표는 상자 안에서 가로로 스크롤합니다. 출퇴근 큰 버튼은 위쪽 아이콘 자리를 비워 글자와 겹치지 않고, 알림 숫자 배지는 종 아이콘 옆으로 옮깁니다. 긴 낱말은 넘치지 않고 줄을 바꿉니다(overflow-wrap) |
| 움직임 줄이기 | HIG-A11y, SEED-Inclusive | 기기에서 움직임 줄이기를 켜면 화면 전환, 시트, 다이얼로그, 토스트의 움직임을 CSS로 끄고, 스크립트의 화면 전환 대기 시간(300ms)도 0으로 둡니다 |
| 키보드 포커스 표시 | FF-a11y, SEED-Inclusive | 키보드로 옮긴 포커스에만 2px 보라 테두리를 보입니다(:focus-visible) |

`fit200.mjs`(임시 점검 스크립트)로 80화면을 글자 크기 200%로 열어, 휴대폰 화면 밖으로 나간 요소(가로 스크롤 상자 안은 빼고), 말줄임으로 잘린 글자, 상자보다 넓은 글자를 찾았습니다. 처음 80화면을 모두 돌렸을 때 32번 급여일 아침의 제목("₩984,528이 들어와요"를 붙여 쓴 줄) 한 곳만 넘쳤고, overflow-wrap을 더한 뒤 32번과 8, 9, 15, 19, 38, 74번을 다시 열어 0건을 확인했습니다. `cap_worker_200/`의 세 화면은 하단 버튼 위 24px 페이드 아래로 본문이 이어지는데, 스크롤하면 모두 보입니다(사장님 앱 200% 캡처와 같은 모양).

## 문구 린트

v9와 같은 10건(목록 칸 모양 버튼 8건: 3번 받을 곳 선택 줄, 8번과 61번 일당 풀이 줄, 9번 달력 날짜 칸 5개, 그리고 51, 52번 KRWt 안내 2건)에, 시트나 확인 창을 여는 목록 행에 role="button"을 붙이면서 덤프 도구가 행 전체 글자를 버튼 이름으로 읽은 "버튼 문법" 지적 16건이 더해져 모두 26건입니다. 새 16건은 퇴근 시간 고르기 줄(23, 77), 고용노동부 상담 1350 줄(27, 38, 39, 40, 51, 68, 79), 받을 곳 줄(28, 31, 51), 사장님께 알림 보내기 줄(38, 39, 40, 79)입니다. 덤프에서 표시만 빼고 v9와 견주면 80화면 모두 글자가 같습니다. 다른 화면으로 가는 행과 안내 상자는 role="link"로 두어 이 지적에서 빠집니다.
