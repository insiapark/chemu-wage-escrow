# 체무 알바생 앱 v15 컴포넌트 목록

알바생 앱(`docs/wireframe/worker.html`)에서 쓰는 컴포넌트를 개발에 넘기기 위한 표입니다. 화면 번호는 화면 목록 순서이자 알바생 앱`docs/wireframe/worker.html?i=번호`입니다(00~82, 83화면). 쓰는 화면은 각 화면을 머리 없는 크롬(480x1200)으로 열어 맨 위 층(확인 창이 열려 있으면 확인 창, 시트면 시트, 전체 화면이면 전체 화면, 아니면 지금 화면과 탭바)에 보이는 것을 센 값입니다. 토큰 이름은 `디자인_토큰.md`, `디자인_토큰_알바생추가.md`, 접근성 방식은 `접근성_점검_알바생.md`, 에러 틀은 `에러_체계_알바생.md`, 움직임은 `모션_알바생.md`를 따릅니다. 사장님 앱과 같은 컴포넌트는 이름과 토큰이 같고(`컴포넌트_사장님.md`), 다른 점만 따로 적었습니다.

모든 컴포넌트에 공통인 것:
- 누르는 대상은 44x44px 이상, 대상 사이는 8px 이상입니다.
- 키보드로 옮긴 포커스에만 2px 보라 테두리(`:focus-visible`, `--fg-brand`)를 보입니다.
- 상태는 색과 함께 글자나 아이콘 모양으로도 보입니다.
- 글자는 rem 단위라 글자 크기 200%에서도 내용이 남습니다. 130% 이상이면 버튼 줄을 세로로 쌓습니다.
- 모서리는 8, 16, 24, 9999px 네 가지(`--radius-s`, `--radius-m`, `--radius-l`, `--radius-full`)만 씁니다.
- 움직임은 완료 순간에만 있고 `--motion-*` 토큰을 씁니다. 움직임 줄이기에서는 모두 꺼집니다.
