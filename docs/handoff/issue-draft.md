# 제목

체무 목데이터 시연 앱과 Sepolia 일당 보관·자동 지급 연동

# 내용

화면 기획만 있던 저장소에서 계약→출퇴근→양측 서명→일당 보관→급여일 지급→기록 대조 흐름을 실행할 수 있도록 구현합니다. 다헌님이 전달한 DailyWageEscrow와 MockKRWt 배포에 연결하며, 실제 테스트넷 모드와 목데이터 모드를 구분합니다.

- [x] 브라우저 로컬 목데이터 앱과 계약·출퇴근·보관·지급 상태 처리
- [x] Sepolia approve/fund, EIP-712 공동 서명, confirmAndLock, release
- [x] EIP-7702 계정의 ERC-1271 확인 및 계정 전환 지연 보완
- [x] 거래 해시 저장, 미확인 영수증 재조회, 새로고침 복원

- [x] 별도 급여일 실행기와 실제 대기→지급 증빙
