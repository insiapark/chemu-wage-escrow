# 본문

계약 동의부터 출퇴근·일당 보관·지급까지 실행할 수 있는 Next.js 시연 앱을 추가합니다. 기본 `/`는 브라우저 로컬 목데이터를 사용하고, `/sepolia`는 전달받은 MockKRWt와 DailyWageEscrow 배포에서 92,880 KRWt 한 건을 실제 보관·지급합니다.

WorkRecord의 원본 SHA-256과 nonce를 양측이 EIP-712로 서명하고, EOA 또는 ERC-1271 검증을 통과하는 EIP-7702 계정으로 확정합니다. 거래 영수증·교체·미확인 상태를 추적하고, JSON을 해당 기록의 WageLocked 이벤트와 대조합니다. 별도 실행기는 기본 읽기 전용이며 `--send`와 프로세스 키를 명시할 때만 급여일에 지급합니다.

## 검증

- 단위 테스트 29개, 브라우저 시나리오 9개 통과.
- TypeScript 검사와 프로덕션 빌드 통과.
- 사용자가 직접 실행한 수동 지급 및 자동 실행기 대기→전송→확인 완료.
- 자동 지급 예정 2026-11-28 02:30:00 KST, 지급 블록 02:30:12 KST, 92,880 KRWt.
- `chemu-sepolia-0.json`, `chemu-sepolia-3.json`의 원본·양측 서명과 실제 Sepolia 이벤트 재검증 통과.
- 공개 기록·실행 로그·조회 캡처: `docs/demo-evidence/2026-11-28/`.

## 리뷰 시 참고

실제 모드의 계약·출퇴근은 준비된 시연 원본이며, API·인증·기기 간 원본 공유·은행 입금은 없습니다. 자동 지급에는 별도 실행기를 계속 켜 두어야 합니다. JSON 대조는 파일 자신의 기록을 확인하므로 정상 과거 파일도 성공합니다. 컨트랙트는 전달받은 기존 배포를 사용했습니다.

개인키와 `.env.local`, 빌드 산출물, node_modules는 포함하지 않습니다. 실행·검증·리허설 안내는 `frontend/README.md`, `docs/handoff/README.md`에 있습니다.
