# 체무 개발 타임라인 (12월 1일 발표 기준)

12월 1일(화) 최종 발표까지 8일입니다. 화면 설계 v15(알바생 앱, 사장님 앱, 기록 대조 웹, 1분 시연 모드)는 끝났으니, 남은 시간은 **시연 12단계 가운데 돈이 실제로 움직이는 다섯 단계를 테스트넷에서 진짜로 돌리는 데** 씁니다. 나머지 단계는 와이어프레임과 1분 시연 모드로 보여 줍니다.

## 무엇을 진짜로 돌리고, 무엇을 와이어프레임으로 보여 주나

| 시연 단계 | 12월 1일에 | 이유 |
|---|---|---|
| 1, 2 계약 올리기와 동의(주휴수당 점검) | 실제 앱 | 계약 조건이 보관 금액을 정하는 출발점 |
| 3 출근하기(가게 30m 안) | 실제 앱, 위치는 모의 값 | 발표장에서 GPS를 쓸 수 없음 |
| 4, 5 근무 확정과 일당 보관 ₩92,880 | **테스트넷 거래** | 서비스의 핵심. 채워 둔 돈에서 보관된 돈으로 옮겨지는 거래를 보여 줌 |
| 8 급여일 자동 입금 ₩984,528 | **테스트넷 거래** | 급여일 시각을 발표 시각 몇 분 뒤로 정해 두고 배포. 발표 중 아무도 누르지 않아도 풀림 |
| 12 기록 대조 | **실제 해시 대조** | 기록 대조 웹(v11)이 브라우저에서 SHA-256을 계산 |
| 6, 7 시간 고침과 이의 | 와이어프레임 | 이의 차액 남겨 두기는 2차 개발 |
| 9, 10 안 들어온 돈, 돈이 모자란 가게 | 와이어프레임 | 다음 날 알림과 일부 채우기는 2차 개발 |
| 11 돈이 움직이는 길 | 와이어프레임 | 설명 화면 |

실제 앱이 막히면 같은 순서의 1분 시연 모드(`docs/wireframe/demo.html`)로 바로 넘어갈 수 있게 둘 다 준비합니다.
