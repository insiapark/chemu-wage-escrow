# 체무 와이어프레임 버전 기록

알바생 앱은 근로자 파트 이성재 님의 와이어프레임 v3(23화면)에서 시작했습니다. 숫자와 정보 구조는 v3 그대로이고, 버전마다 아래를 더했습니다.

| 버전 | 바뀐 것 | 알바생 | 사장님 |
|---|---|---|---|
| v3 | 이성재 님 원본. 페르소나 A님(주말 편의점 야간), B님(평일 점심 식당), 정상 흐름, 고친 기록, 급여일, 체불 위험 | 23 | |
| v4 | 빠져 있던 상태 화면(가게 30m 밖, 확정 대기, 이의 결과, 입금 실패), 3D 아이소메트릭 그림 16장, 토스 라이팅 원칙, 화면마다 기획 주석. 사장님 앱을 같은 틀로 새로 만듦 | 30 | 28 |
| v5 | 실제로 쓰다 막히는 흐름: 본인 확인, 계좌 확인, 알림 허용, 위치 꺼짐, 인터넷 끊김, 퇴근 누락, 휴게 못 쉼, 근무 달력, 일당과 주휴수당 계산 풀이, 노동청 진정 안내. 사장님 앱은 알바 3명(A, C, D님), 반복 근무표, 결근, 인건비가 모자랄 때, 자동 채우기, 인건비 리포트. 사장님 돈 이름을 "채워 둔 돈"과 "보관된 돈"으로 나눔 | 48 | 43 |
| v6 | 모의 사용자 여섯 명(알바생 둘, 사장님 둘, UX 라이터, 은행 실무자) 검수 반영. 손해를 감추던 버튼 문구, B님 금액 한 카드로, 보내기 전 확인, 돈이 모자란 사장님에게 세 가지 길, "지급 날짜 알리기" 새 기능, 원화 스테이블코인 수령은 법이 정비될 때까지 시연용 | 52 | 44 |
| v7 | "돈이 움직이는 길" 설명 화면, 누르고 나서야 열리던 상태와 확인 창을 화면 목록에 올림, 두 앱 주석에서 상대 앱 화면을 바로 여는 링크, 시연 순서와 흐름 정의 | 80 | 47 |
