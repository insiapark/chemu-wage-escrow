# 체무 오픈소스 참고 목록

원화 스테이블코인과 베스팅으로 아르바이트 임금 체불을 막는 서비스의 README와 화면기획서에 쓰는 참고 저장소와 3D 아이콘 출처입니다.

기준일 2026-11-23. 별 수는 GitHub API 값을 반올림한 근사치입니다. 라이선스는 저장소의 LICENSE 파일과 소스 SPDX 표기를 기준으로 적었습니다.

## 먼저 볼 다섯 개

| 순서 | 저장소 | 쓰임 |
|---|---|---|
| 1 | OpenZeppelin Contracts (VestingWallet, EIP712, MerkleProof) | 락업 지갑, 쌍방 서명 검증, 출퇴근 기록 증명을 한 라이브러리로 해결 |
| 2 | scaffold-eth-2 | 테스트넷 시연 앱의 출발점 (Next.js, Hardhat, wagmi, viem, RainbowKit 묶음) |
| 3 | OpenZeppelin Contracts v4.9 escrow (ConditionalEscrow, RefundEscrow) | 급여일 조건부 지급과 근무 취소 환불 흐름 |
| 4 | Sablier evm-monorepo (Lockup, Flow) | 구간 해제 구조와 미지급 부채 추적 개념을 화면과 설계에 참고 |
| 5 | realvjy/3dicons | CC0 3D 아이콘, 화면기획서 시각 요소 |
