## 최준우에게

- 바뀐 경계: `EscrowGateway`에 `releaseDue(now)`를 더했습니다. 이미 입금된 상태면 거래 없이 지금 상태를 돌려줍니다. 급여일 타이머만 이 함수를 씁니다. 실제 HTTP·컨트랙트 구현으로 바꿀 때 같은 뜻(이미 지급된 건은 건너뛰기)으로 맞춰 주세요. `watch-payday.ts`가 이미 그렇게 합니다.
- 새 파일: `src/lib/format.ts`(금액·날짜 표기), `src/lib/demo-steps.ts`(발표 8단계 계산, 공유 상태만 봄), `src/app/icon.svg`, `tests/demo-flow.test.ts`(`npm test`에 등록).
- 화면 문구가 v79 설계 용어로 바뀌어 버튼 이름도 달라졌습니다. 발표 대본은 `frontend/README.md` 목데이터 시연 순서를 새 이름으로 고쳐 두었습니다.

- 판단이 필요한 것: P2 9(사장님 확정 한 번 누르기), 10(계약 전 891,648원), 11(지갑·Sepolia 문구)입니다. Sepolia 모드 화면(KRWt, 지급 같은 말)은 이번에 손대지 않았습니다.
